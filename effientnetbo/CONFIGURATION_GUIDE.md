## Model & File Paths

Located at the top of `mediapipe_gesture_recognition.py`:

### `MODEL_WEIGHTS`
```python
MODEL_WEIGHTS = "efficientnet_asl.h5"
```
- **Description**: Path to trained model weights
- **Type**: String (file path)
- **Default**: `"efficientnet_asl.h5"`
- **Usage**: Typically should not change unless you have multiple models

### `LABELS_FILE`
```python
LABELS_FILE = "label_classes.npy"
```
- **Description**: Path to class label mappings
- **Type**: String (file path)
- **Default**: `"label_classes.npy"`
- **Generated by**: `train_hydenet.py`

### `SAVE_DIR`
```python
SAVE_DIR = "dataset/test/captured_gestures"
```
- **Description**: Directory where captured frames are saved
- **Type**: String (directory path)
- **Default**: `"dataset/test/captured_gestures"`
- **Auto-created**: Yes, if it doesn't exist

## Detection & Confidence

### `CONFIDENCE_THRESHOLD`
```python
CONFIDENCE_THRESHOLD = 0.70
```
- **Description**: Minimum confidence to consider prediction "DETECTED"
- **Range**: 0.0 - 1.0
- **Default**: 0.70
- **Effect**:
  - **Lower (e.g., 0.5)**: More detections, but more false positives
  - **Higher (e.g., 0.9)**: Fewer detections, but higher accuracy
- **Recommendation**:
  - 0.5-0.6: Very permissive, test phase
  - 0.7-0.8: Balanced, production
  - 0.9+: Very strict, high precision needed

### `MC_PASSES`
```python
MC_PASSES = 10
```
- **Description**: Number of Monte Carlo inference passes for uncertainty estimation
- **Range**: 1-50 (practical)
- **Default**: 10
- **Effect**:
  - **Lower (e.g., 5)**: Faster inference, less stable
  - **Higher (e.g., 20)**: Slower inference, more robust
- **Trade-off**: Speed vs. Accuracy
- **Recommendation**:
  - 5: Real-time performance priority
  - 10: Balanced (default)
  - 20+: Accuracy priority

## MediaPipe Settings

### `MEDIAPIPE_CONFIDENCE`
```python
MEDIAPIPE_CONFIDENCE = 0.7
```
- **Description**: Minimum confidence threshold for MediaPipe hand detection
- **Range**: 0.0 - 1.0
- **Default**: 0.7
- **Effect**:
  - **Lower (e.g., 0.5)**: Detects more hands, may include false positives
  - **Higher (e.g., 0.9)**: Only detects clear hands
- **Recommendation**:
  - 0.5: Permissive (low light, partial hand)
  - 0.7: Balanced (default)
  - 0.9: Strict (clear detection only)

### `HAND_DETECTION_MODEL`
```python
HAND_DETECTION_MODEL = "full"
```
- **Description**: Complexity level of hand detection model
- **Options**:
  - `"lite"` (model_complexity=0): Faster, less accurate
  - `"full"` (model_complexity=1): Slower, more accurate
- **Default**: `"full"`
- **Trade-off**: Speed vs. Accuracy
- **Recommendation**:
  - "lite": Real-time streaming (FPS priority)
  - "full": Accurate detection (accuracy priority)

## Smoothing & Stability

### `BUFFER_SIZE`
```python
BUFFER_SIZE = 8
```
- **Description**: Size of temporal smoothing buffer for predictions
- **Range**: 1-50
- **Default**: 8
- **Effect**:
  - **Smaller (e.g., 3)**: Responsive, may be jittery
  - **Larger (e.g., 15)**: Smooth, but delayed
- **Explanation**: Averages last N prediction frames
- **Recommendation**:
  - 5-8: Balanced (default)
  - 3: Quick response needed
  - 15+: Smooth predictions critical

### `CONSECUTIVE_FRAMES`
```python
CONSECUTIVE_FRAMES = 5
```
- **Description**: Number of consecutive high-confidence frames needed to auto-save
- **Range**: 1-30
- **Default**: 5
- **Effect**:
  - **Lower (e.g., 2)**: Save more frequently
  - **Higher (e.g., 10)**: Save only very stable predictions
- **Recommendation**:
  - 3-5: Balanced (default)
  - 2: Experimental phase
  - 10+: High-quality dataset only

## Visualization

### `HAND_BOX_COLOR`
```python
HAND_BOX_COLOR = (0, 255, 0)
```
- **Description**: Color of bounding box in BGR format
- **Type**: Tuple (B, G, R)
- **Default**: `(0, 255, 0)` - Green
- **Common Options**:
  - `(0, 255, 0)`: Green
  - `(255, 0, 0)`: Blue
  - `(0, 0, 255)`: Red
  - `(0, 255, 255)`: Yellow

### `HAND_BOX_THICKNESS`
```python
HAND_BOX_THICKNESS = 2
```
- **Description**: Line thickness of bounding box
- **Range**: 1-10
- **Default**: 2
- **Recommendation**:
  - 1-2: Thin (default)
  - 3-4: Visible
  - 5+: Very prominent

### `LANDMARK_COLOR`
```python
LANDMARK_COLOR = (0, 0, 255)
```
- **Description**: Color of hand landmarks (joint markers) in BGR format
- **Type**: Tuple (B, G, R)
- **Default**: `(0, 0, 255)` - Red
- **Common Options**: Same as above

### `LANDMARK_RADIUS`
```python
LANDMARK_RADIUS = 4
```
- **Description**: Radius of landmark circles
- **Range**: 1-10
- **Default**: 4
- **Recommendation**: 3-5 for visibility

## Performance Tuning

### For Maximum Speed (Real-time Priority)
```python
MC_PASSES = 5                          # Reduce inference passes
HAND_DETECTION_MODEL = "lite"          # Use faster model
BUFFER_SIZE = 3                        # Less smoothing
LANDMARK_RADIUS = 2                    # Smaller circles (faster draw)
```
**Expected FPS**: 20-30+ (on GPU)

### For Maximum Accuracy (Accuracy Priority)
```python
MC_PASSES = 20                         # More inference passes
HAND_DETECTION_MODEL = "full"          # More accurate model
BUFFER_SIZE = 15                       # More smoothing
MEDIAPIPE_CONFIDENCE = 0.9             # Strict detection
CONFIDENCE_THRESHOLD = 0.85            # Strict classification
```
**Expected FPS**: 8-15 (on CPU)

### Balanced Configuration (Recommended)
```python
MC_PASSES = 10                         # Default
HAND_DETECTION_MODEL = "full"          # Good accuracy
BUFFER_SIZE = 8                        # Smooth predictions
MEDIAPIPE_CONFIDENCE = 0.7             # Balanced
CONFIDENCE_THRESHOLD = 0.70            # Balanced
```
**Expected FPS**: 12-20 (on CPU), 25-30 (on GPU)

## Bounding Box Padding

The `get_hand_bounding_box` function has a `padding` parameter:

```python
bbox = get_hand_bounding_box(
    hand_landmarks.landmark,
    width, height,
    padding=20  # ← Adjust this
)
```

- **Lower (e.g., 10)**: Tight bounding box around hand
- **Higher (e.g., 30)**: Larger crop area, includes more background
- **Default**: 20
- **Recommendation**:
  - 15-20: Standard (default)
  - 25-30: Include more context

## Environment Variables

You can also set configurations via environment variables:

```python
import os

# Override defaults with environment variables
MC_PASSES = int(os.getenv("MC_PASSES", "10"))
CONFIDENCE_THRESHOLD = float(os.getenv("CONFIDENCE_THRESHOLD", "0.70"))
HAND_DETECTION_MODEL = os.getenv("HAND_DETECTION_MODEL", "full")
```

Usage:
```bash
export MC_PASSES=5
export CONFIDENCE_THRESHOLD=0.80
python mediapipe_gesture_recognition.py
```

## Need Help?

- **Slow inference**: Reduce `MC_PASSES`, use "lite" model
- **Unstable predictions**: Increase `BUFFER_SIZE`
- **Missing detections**: Lower `MEDIAPIPE_CONFIDENCE`
- **Too many false positives**: Increase `CONFIDENCE_THRESHOLD`
- **Jerky video**: Increase `BUFFER_SIZE`
- **Delayed response**: Reduce `BUFFER_SIZE`

See `MEDIAPIPE_SETUP_GUIDE.md` for more troubleshooting.
